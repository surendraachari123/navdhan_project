📊 System Overview

Purpose: The Account Book is the central financial record system maintaining investor accounts, investment activity, holdings, balances, and transaction history.

Key Principles:

  • Orders/Requests ≠ Completed Transactions
  • Holdings updated only on confirmed transactions
  • NAV applied based on cut-off rules
  • Full audit trail maintained

🛤️ Highlighted Paths

Path A - SIP Flow:

Investor → SIP Registration → Installment → Transaction Ledger → Unit Allocation → Holdings → Portfolio Report

Path B - Lumpsum Flow:

Investor → Lumpsum Order → Payment → NAV Application → Transaction Ledger → Holdings

Path C - Redemption Flow:

Investor → Withdrawal Request → Eligibility → Redemption NAV → Units Redeemed → Holdings Updated → Settlement
